One emoji, one dream vacation: a palm tree — warm sun, white sand, slow
days, nowhere to be. It is the whole trip in a single character.

## How it works

Run `python3 main.py`. It writes exactly one emoji, 🌴, to
`/output/entry.txt` with no trailing newline. Before writing, it asserts
the gate: the entry is 1–8 characters, non-whitespace, and exactly one
emoji character. After writing, it reads the file back and verifies the
contents match the emoji exactly.
